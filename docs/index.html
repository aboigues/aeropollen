AeroPollen

Deux champs de données Connect IQ pour cyclocomputeurs Garmin Edge : qualité de l'air et niveaux de pollens à votre position, en direct, pendant l'effort.

Télécharger la dernière version Voir le code source

Deux champs, chacun installable indépendamment

Qualité de l'air

Indice européen de qualité de l'air (European AQI) à la position GPS courante, mis à jour en arrière-plan pendant l'activité.

Pollens

Score de pollen global (bouleau, graminées, ambroisie, olivier...) à votre position, pour anticiper les zones à risque allergique.

Installation

  1. Télécharger les fichiers .prg de la dernière Release (un par champ de données).
  2. Connecter l'appareil Garmin en USB — il apparaît comme un volume de stockage nommé GARMIN.
  3. Copier les fichiers .prg dans le dossier Garmin/Apps/ de l'appareil.
  4. Débrancher l'appareil (éjection propre recommandée), puis le redémarrer si besoin.
  5. Sur l'appareil : Menu → Profils d'activité → Écrans de données → Ajouter un champ, puis chercher « AeroPollen Air » ou « AeroPollen Pollens ».

Pour compiler le projet soi-même ou contribuer, voir le README du dépôt.

Confidentialité

La position GPS courante est transmise, en HTTPS, à l'API publique Open-Meteo à chaque rafraîchissement en arrière-plan (au minimum toutes les 15 minutes pendant une activité), uniquement pour obtenir la qualité de l'air et les niveaux de pollens à cette position. Aucune clé d'API, aucun identifiant de compte, aucune donnée personnelle autre que la position n'est transmis. Le dernier relevé est mis en cache localement sur l'appareil et n'est jamais transmis ailleurs. Code source entièrement ouvert — voir l'audit de sécurité.
