Pourquoi AeroPollen

L'info qui manque sur votre compteur

Votre Edge affiche déjà votre vitesse, votre fréquence cardiaque, votre dénivelé. Il ne vous dit jamais si l'air que vous respirez à cet instant précis est bon à respirer, ou si le taux de pollens va déclencher votre allergie à mi-parcours.

Qualité de l'air en direct

Indice européen de qualité de l'air (European AQI) calculé à votre position GPS exacte, pas à la station de mesure la plus proche à 30 km.

Alerte pollens

Score de pollen global (bouleau, graminées, ambroisie, olivier...) pour anticiper les zones à risque avant que les yeux ne piquent.

Zéro friction

Mise à jour automatique en arrière-plan pendant l'activité. Pas de bouton à appuyer, pas d'app à ouvrir, pas de ralentissement de votre GPS.

Fonctionnement

Simple, discret, fiable

Votre position

Le GPS de votre Edge donne votre position courante pendant l'activité.

Interrogation en arrière-plan

Toutes les 15 minutes maximum, AeroPollen interroge Open-Meteo en HTTPS, sans jamais bloquer l'affichage ni le tracking GPS.

Affiché à l'écran

La dernière valeur connue s'affiche instantanément sur votre écran de données, jamais de temps de chargement.

Installation

Prêt en 5 minutes

  1. Télécharger les fichiers .prg de la dernière Release (un par champ de données).
  2. Connecter l'appareil Garmin en USB — il apparaît comme un volume de stockage nommé GARMIN.
  3. Copier les fichiers .prg dans le dossier Garmin/Apps/ de l'appareil.
  4. Débrancher l'appareil (éjection propre recommandée), puis le redémarrer si besoin.
  5. Sur l'appareil : Menu → Profils d'activité → Écrans de données → Ajouter un champ, puis chercher « AeroPollen Air » ou « AeroPollen Pollens ».

Pour compiler le projet soi-même ou contribuer, voir le README du dépôt.

Questions fréquentes

FAQ

Est-ce que ça consomme beaucoup de batterie ?

La mise à jour se fait au maximum toutes les 15 minutes, en arrière-plan, sans jamais garder le GPS ou l'écran allumés plus longtemps que d'habitude. L'impact est comparable à n'importe quel champ de données utilisant le réseau.

Pourquoi deux applications séparées plutôt qu'une seule ?

C'est une contrainte de la plateforme Connect IQ : un fichier de manifeste ne peut déclarer qu'une seule application. Les deux partagent tout leur code via une bibliothèque commune (Monkey Barrel), mais s'installent et se configurent indépendamment.

Mes données GPS sont-elles vendues ou revendues ?

Non. La position est envoyée uniquement à Open-Meteo (fournisseur de données météo), en HTTPS, pour la requête en cours. Aucune clé d'API, aucun compte, aucun tracking. Voir la section Confidentialité du README pour le détail complet.

Est-ce gratuit et le restera-t-il ?

Oui, entièrement gratuit, sous licence libre GPL-3.0. Le code appartient à la communauté, pas à une entreprise — personne ne peut le rendre payant sans le forker sous une autre licence.

Puis-je contribuer ou signaler un bug ?

Avec plaisir — le dépôt est ouvert aux issues et aux Pull Requests. Voir la section Contribuer du README pour les règles du projet.
